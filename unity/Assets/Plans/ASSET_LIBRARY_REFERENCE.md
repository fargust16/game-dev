## Purpose

Registry of third-party packages added to the project and **which System Card / Track in [17](../../../17%20Game%20Systems%20Architecture.md) each one serves**. An agent picking up a terrain, vegetation, animation, or UI-motion task should check this table before reaching for a different tool or writing custom code — these packages are the locked defaults for their domain.

Every row is verified against what is actually present on disk at the date above, not the asset's marketing description. Status `Not imported` means: do not write code against it yet, and do not assume its class names — import first, then update this row with the real API surface.

At runtime, `DirectMatricesHolder.ValueAtPositionInterpolated("height", x, z)` on the generated tile's Terrain GameObject is the O(1) sampling call `IBiomeSampler`/`ITerrainChunkBuilder` use — do **not** use the component's own `FindHolder`/`FindValueAtPosition` helpers (they `FindObjectsByType` scan every call, explicitly flagged "not quick, just an example" in MapMagic's own source); `IChunkStreamer` should cache the holder per resident `ChunkCoord` itself.<br><br>**No dedicated Objects/Scatter/Biome/River node pack is present** (icons for them exist in `Core/Editor/Resources`, but no compiled generator classes do — those are separate downloads from the author). It seeds both the graph-level `graph.random` (`Den.Tools.Noise`) and the `Noise200` node's own `seed` field from `WorldSeed.Fork("terrain")`, and saves the graph to `Assets/Settings/OverworldTerrainGraph.asset`. Current recipe (iterated live with the user in-Editor, 2026-08-09): `PlateauNoise` (flat base, low intensity) blended with a `MountainNoise → Levels` cutoff (huge noise period so only a slice is visible, no tiling) → `Erosion200` → both `HeightOutput200` (visible Terrain) and `DirectMatricesOutput200` (named `"height"` channel for runtime queries). `SimpleForm200` was tried first for a single deliberate mountain stamp but tiled across the tile regardless of its `Wrap` setting (root cause unresolved — its "chunk-size-relative" sizing behaved unexpectedly) — replaced with the noise+Levels approach, which is a plain function of world position and can't repeat inside one tile. `unity/Assets/Scripts/World/Terrain/` (`IBiomeSampler`, `BiomeClassifier`, `MapMagicBiomeSampler`) now reads that channel and classifies height into `BiomeId` (Swamp/Meadow/Forest/Mountain) — height-only bands, no moisture axis yet.<br><br>**Editor-only generation gotcha:** outside Play mode, `MapMagicObject.Update()` only recalculates tile distances (`distsOnly = !isPlaying`) and never constructs a tile on its own — nothing appears without either entering Play mode (tiles then stream around a runtime focus) or explicitly calling `mapMagic.tiles.Pin(coord, asDraft:false, holder:mapMagic)`, which `OverworldTerrainMenu.cs` does for the origin tile. Any future runtime `IChunkStreamer` (W0.5) needs the same awareness: Play-mode streaming and Editor-time pinning are two different code paths in MapMagic, not one. |

## Import instructions (for the two missing packages)

Both are Unity Editor actions only the project owner can perform (Asset Store purchase/ownership + Package Manager UI):

1. Unity Editor → **Window → Package Manager** → **My Assets** (or Asset Store window) → find MapMagic 2 / More Effective Coroutines → **Import**.
2. Let Unity resolve `.meta` files, commit the resulting `Assets/`/`Packages/` changes.
3. Update this file's registry rows with the real namespaces/classes once imported — do not guess them in advance.

## Forbidden / avoid

Same acceptance filter as [PROCEDURAL_TOWN_ASSET_LIBRARY.md](PROCEDURAL_TOWN_ASSET_LIBRARY.md) applies to any future addition to this registry: prefer blocks (materials/modules/props/clip libraries) over finished scenes or competing generators. Do not add a package to this file — or wire code against it — until it is actually present on disk.
