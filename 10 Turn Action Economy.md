# 10 Turn Action Economy — Retired

Status: Deprecated

This document's former Move + Action + Bonus model is rejected and must not be used.

The combat action economy is now defined exclusively in [10.2 Combat System Draft](10.2%20Combat%20System%20Draft.md), which specifies the Action Point (AP) model.

The shared world clock and time-dependent activity rules are defined in [18 World Time and Living Simulation](18%20World%20Time%20and%20Living%20Simulation.md).

The former document contained no unique approved mechanics that need to be carried forward. Initiative, movement, Break Away, Spare, Yield, and Approach interactions are covered by the current combat, grid, and confrontation documents.

This stub is retained only to make the retirement explicit for any old bookmarks. Do not add new references to this file.
