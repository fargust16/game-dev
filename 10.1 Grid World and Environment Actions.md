# Purpose

This document locks the spatial foundation of the game:

> The world is authored and generated for **Turn-Based Mode on a grid**. Movement, cover, traversal, and most environment interactions are grid-native from the start.

Exploration may still feel continuous in camera/presentation, but the truth of space is the grid.

# Central Rules

1. Levels, props, and traversal are designed on the grid first — not painted freely and then forced into turns later.
2. Pathfinding and Move use grid paths (click-to-move runs A* on walkable cells; diagonals allowed without corner-cutting).
3. Environment Actions are first-class turn verbs with costs and failure chances. On an automatic click-path they resolve as successful traversal; manual **E** in WASD control keeps the fail roll.
4. Failure is valuable: a failed climb/jump can make noise, waste the Action, cause injury, or force Confront.
5. V1 keeps a small Environment Action list; do not invent parkour simulator depth.

# Grid

## V1 Grid Model

- Square grid for V1 (simplest solo implementation).
- Each cell has:
  - walkability;
  - elevation / height band;
  - cover/traversal tags;
  - occupancy (creature / large prop).
- Diagonal movement: allowed with simple consistent cost rule (same as orthogonal, or 1.5 — pick one in implementation and keep it).
- Vertical change uses stairs/ladders/climb tags, not free flying.

Exact cell size is technical (for example human-scale ~1m), but all content must snap to that module.

## Authoring Rule

When placing a crate, window, wall, coach, or stair:

- it occupies clear cells;
- it exposes allowed Environment Actions on adjacent cells;
- it does not rely on off-grid precision for gameplay truth.

Visual mesh may overhang slightly for art, but gameplay tests the grid.

## Generation / Blockout Rule

World Seed and hand greybox both produce:

- floor cells;
- blocked cells;
- tagged interactive cells (window, low wall, climbable, jump-gap, door);
- path-connected routes between landmarks.

S0 greybox must already be grid-legal.

# Movement on Grid

Move spends movement points cell by cell along a legal path.

Blocked by:

- walls;
- occupied cells (unless squeezing rule added later);
- missing climb/jump tags where elevation changes.

In non-combat Turn-Based Mode, the same path rules apply so players practice traversal before Confront.

# Environment Actions

Environment Actions are contested or risky ways to use the space.

They usually consume **Action** (decisive/risky) or rarely **Bonus** (trivial adjacent interact already unlocked).

## V1 Environment Action Set

| Action | Typical tag | Economy | Failure examples |
|--------|-------------|---------|------------------|
| **Open / Close** | door, shutter | Action or Bonus if unlocked/trivial | jammed, noisy, alerts |
| **Vault / Jump** | low wall, gap, crate line | Action | fall short, prone/Hurt, noise |
| **Climb Up** | climbable wall, ladder, pipe | Action | slip, noise, fall Hurt |
| **Climb Through Window** | window entry | Action | stuck/noisy entry, cut Hurt, spotted |
| **Mantle Onto** | crate, coach roof, ledge | Action | fail to mount, noise |
| **Kick / Breach** | weak door/crate | Action | loud success or loud fail; may start Confront |
| **Take Cover** | cover cell edge | Bonus or free facing rule (pick one in impl.) | none / wrong side |

V1 does not need swimming, complex parkour chains, or cinematic ledge systems.

## Success and Failure

Each risky Environment Action has:

- a readable chance influenced by traits/skills/Pathway lean later;
- a concrete fail result (noise, Hurt, wasted Action, discovered);
- never empty “nothing happened” as the only fail for important attempts.

Player Knowledge teaches which windows are watched, which walls are climbable, which jumps are foolish.

## Approach Mapping

| Approach | Environment use |
|----------|-----------------|
| Veil | climb window quietly, mantle for eavesdrop angle |
| Confront | breach door, vault into melee |
| Withdraw / Break Away | jump gap / climb to escape route |
| Exchange / Convince | usually not traversal, but may need to reach a private cell first |
| Threaten | brandish from elevated mantle cell |

# Cover and Elevation

V1 soft rules:

- higher cell can grant simple advantage tell for Veil observation or Confront pressure;
- cover tags reduce chance to be spotted or hit (numbers later);
- factory walls, coaches, crates, and stair landings are the main Vertical Slice toys.

# Vertical Slice Implications

Lower Veil greybox must include grid-tagged examples:

- crate vault on Tincture Row;
- window climb into or past Harrow side;
- low wall / coach vault on Loom Lane;
- climbable coal-stair ledge;
- breachable weak shutter for POI C nook.

These exist even before full Confront so S0/S1 can validate traversal readability.

# Solo Scope

## V1

- square grid truth;
- pathfinding Move;
- small Environment Action set above;
- fail = noise / Hurt / spotted / wasted Action;
- all Vertical Slice landmarks grid-snapped.

## V2

- richer cover;
- better stealth modifiers by cell tags;
- more furniture verbs.

## V3

- denser generated tag grammar from World Seed;
- still reject freeform physics parkour as gameplay truth.

# Anti-Patterns

- building pretty off-grid levels and bolting turns on later;
- Environment Actions only in cutscenes;
- 0% fail fantasy jumps that delete Commitment;
- giving Confront unique traversal verbs denied to Veil/Withdraw;
- giant action list before the six Approaches feel good.
