# Purpose

This document locks the **spatial foundation of the Combat Grid**:

> When Confront starts, a square grid forms around the player from the scene's real geometry. NPCs fighting elsewhere have no grid: they are simulated. Outside Confront, overworld and interior exploration are free third-person spaces without grid gameplay truth ([16 Architecture Pivot](16%20Architecture%20Pivot.md)).

# Central Rules

1. Cover and traversal come from the scene's geometry, read onto the grid when Confront starts.
2. Pathfinding and Move use grid paths (A* on walkable cells; diagonals allowed without corner-cutting).
3. Environment Actions are first-class combat actions with AP costs and failure chances.
4. Failure is valuable: a failed climb/jump can waste the Action, cause injury, or worsen position — not empty “nothing happened.”
5. V1 keeps a small Environment Action list; do not invent parkour simulator depth.
6. Outside Confront, overworld and interiors do **not** use this grid as movement truth. Diegetic interacts there are separate.

# Grid (During Confront Only)

## V1 Grid Model

- Square grid for V1 (simplest solo implementation).
- Each cell has:
  - walkability;
  - elevation / height band;
  - cover/traversal tags;
  - occupancy (creature / large prop).
- Diagonal movement: allowed with one consistent cost rule (same as orthogonal, or 1.5 — pick in implementation and keep it).
- Vertical change uses stairs/ladders/climb tags, not free flying.

Exact cell size is technical (for example human-scale ~1m).

## Authoring Rule

When placing a crate, window, wall, coach, or stair in the world:

- it carries the tags the grid needs when a fight starts;
- it exposes allowed Environment Actions on adjacent cells;
- it does not rely on off-grid precision for gameplay truth during Confront.

Visual mesh may overhang slightly for art, but gameplay tests the grid.

## Construction Rule

When Confront starts, the grid is built from the current scene and produces:

- floor cells;
- blocked cells;
- tagged interactive cells (window, low wall, climbable, jump-gap, cover);
- concealment from vegetation.

An interior scene has its own grid. The grid reaches 20 cells from the player in every direction. How it reads terrain slopes and generated buildings, and what happens at its edge, is open (CC-33).

# Movement on Grid

Movement consumes AP according to the movement-cost rules in [10.2 Combat System Draft](10.2%20Combat%20System%20Draft.md), and traverses legal grid cells along a path.

Blocked by:

- walls;
- occupied cells (unless squeezing rule added later);
- missing climb/jump tags where elevation changes.

# Environment Actions

Environment Actions are contested or risky ways to use the space around a fight.

Every Environment Action has an explicit AP cost defined by its action rules. There is no separate Move / Action / Bonus category.

## V1 Environment Action Set

| Action | Typical tag | Economy | Failure examples |
|--------|-------------|---------|------------------|
| **Open / Close** | door, shutter | AP cost defined by interaction complexity | jammed, noisy |
| **Vault / Jump** | low wall, gap, crate line | AP cost | fall short, prone/Hurt |
| **Climb Up** | climbable wall, ladder, pipe | AP cost | slip, fall Hurt |
| **Climb Through Window** | window entry | AP cost | stuck, cut Hurt |
| **Mantle Onto** | crate, coach roof, ledge | AP cost | fail to mount |
| **Kick / Breach** | weak door/crate | AP cost | loud fail; wasted AP |
| **Take Cover** | cover cell edge | AP cost or explicit free rule (to be decided) | wrong side |

V1 does not need swimming, complex parkour chains, or cinematic ledge systems.

## Success and Failure

Each risky Environment Action has:

- a readable chance using the shared attribute/skill check foundation in [07.1 Character Attributes, Skills, and Action Checks](07.1%20Character%20Attributes,%20Skills,%20and%20Action%20Checks.md), where applicable; situational modifiers and the final probability curve remain open;
- a concrete fail result (Hurt, wasted Action, bad position);
- never empty “nothing happened” as the only fail for important attempts.

## Approach Mapping

| Approach | Environment use |
|----------|--------------------------|
| Veil | mantle / cover for concealment |
| Confront | breach, vault into melee |
| Withdraw / Break Away | jump gap / climb toward escape edge |
| Exchange / Convince | usually not traversal |
| Threaten | brandish from elevated mantle cell |

# Cover and Elevation

V1 soft rules:

- higher cell can grant simple advantage tell for Confront pressure;
- cover tags reduce chance to be hit (numbers later);
- World props (crates, coaches, pillars, trees) are the main toys.

# Vertical Slice Implications

The slice must prove the Combat Grid in the city with:

- walkable grid over real geometry;
- cover from world props;
- one vault or mantle tag;
- a character leaving the fight by moving away.

Outside Confront, the overworld stub and interior scenes stay free-move.

# Solo Scope

## V1

- square grid truth **during Confront only**;
- pathfinding Move;
- small Environment Action set above;
- fail = Hurt / wasted Action / bad position.

## V2

- richer cover;
- more furniture verbs;
- more tagged world props.

## V3

- denser generated tags from seed;
- still reject freeform physics parkour as gameplay truth.

# Anti-Patterns

- treating overworld or interiors as grid-authored gameplay space outside Confront;
- building pretty places and bolting turns on later without cell tags;
- Environment Actions only in cutscenes;
- 0% fail fantasy jumps that delete Commitment;
- giving Confront unique traversal verbs denied to Veil/Withdraw;
- giant action list before the six Approaches feel good.
