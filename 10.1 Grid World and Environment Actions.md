# Purpose

This document locks the **spatial foundation of Combat Arenas**:

> Square-grid truth applies on **Combat Arena scenes** during Confront. Overworld and interior exploration are free third-person spaces without grid gameplay truth ([16 Architecture Pivot](16%20Architecture%20Pivot.md)).

# Central Rules

1. Arena props, cover, and traversal are designed on the grid first.
2. Pathfinding and Move use grid paths (A* on walkable cells; diagonals allowed without corner-cutting).
3. Environment Actions are first-class **arena** turn verbs with costs and failure chances.
4. Failure is valuable: a failed climb/jump can waste the Action, cause injury, or worsen position — not empty “nothing happened.”
5. V1 keeps a small Environment Action list; do not invent parkour simulator depth.
6. Overworld / interiors do **not** use this grid as movement truth. Diegetic interacts there are separate.

# Grid (Arenas Only)

## V1 Grid Model

- Square grid for V1 (simplest solo implementation).
- Each cell has:
  - walkability;
  - elevation / height band;
  - cover/traversal tags;
  - occupancy (creature / large prop).
- Diagonal movement: allowed with one consistent cost rule (same as orthogonal, or 1.5 — pick in implementation and keep it).
- Vertical change uses stairs/ladders/climb tags, not free flying.

Exact cell size is technical (for example human-scale ~1m). Arena Theme Packs snap to that module.

## Authoring Rule (Theme Packs)

When placing a crate, window, wall, coach, or stair **on an arena**:

- it occupies clear cells;
- it exposes allowed Environment Actions on adjacent cells;
- it does not rely on off-grid precision for gameplay truth.

Visual mesh may overhang slightly for art, but gameplay tests the grid.

## Generation / Blockout Rule

Arena Theme Packs (street, tavern, cellar, woods, …) produce:

- floor cells;
- blocked cells;
- tagged interactive cells (window, low wall, climbable, jump-gap, cover);
- readable spawn sides for player and hostiles.

Arenas must feel thematically related to the source location; they need not clone exploration geometry.

# Movement on Grid

Move spends movement points cell by cell along a legal path.

Blocked by:

- walls;
- occupied cells (unless squeezing rule added later);
- missing climb/jump tags where elevation changes.

# Environment Actions (Arena)

Environment Actions are contested or risky ways to use arena space.

They usually consume **Action** (decisive/risky) or rarely **Bonus** (trivial adjacent interact).

## V1 Environment Action Set

| Action | Typical tag | Economy | Failure examples |
|--------|-------------|---------|------------------|
| **Open / Close** | door, shutter | Action or Bonus if unlocked/trivial | jammed, noisy |
| **Vault / Jump** | low wall, gap, crate line | Action | fall short, prone/Hurt |
| **Climb Up** | climbable wall, ladder, pipe | Action | slip, fall Hurt |
| **Climb Through Window** | window entry | Action | stuck, cut Hurt |
| **Mantle Onto** | crate, coach roof, ledge | Action | fail to mount |
| **Kick / Breach** | weak door/crate | Action | loud fail; wasted Action |
| **Take Cover** | cover cell edge | Bonus or free facing rule (pick one in impl.) | wrong side |

V1 does not need swimming, complex parkour chains, or cinematic ledge systems on arenas.

## Success and Failure

Each risky Environment Action has:

- a readable chance influenced by traits/skills/Pathway lean later;
- a concrete fail result (Hurt, wasted Action, bad position);
- never empty “nothing happened” as the only fail for important attempts.

## Approach Mapping

| Approach | Environment use on arena |
|----------|--------------------------|
| Veil | mantle / cover for concealment |
| Confront | breach, vault into melee |
| Withdraw / Break Away | jump gap / climb toward escape edge |
| Exchange / Convince | usually not traversal |
| Threaten | brandish from elevated mantle cell |

# Cover and Elevation

V1 soft rules:

- higher cell can grant simple advantage tell for Confront pressure;
- cover tags reduce chance to be hit (numbers later);
- Theme Pack props (crates, coaches, pillars, trees) are the main toys.

# Vertical Slice Implications

Post-pivot slice must prove at least one arena Theme Pack with:

- walkable grid;
- cover props;
- one vault or mantle tag;
- clear Break Away edge fiction.

Overworld stub and one interior scene stay free-move (no grid).

# Solo Scope

## V1

- square grid truth **on arenas only**;
- pathfinding Move;
- small Environment Action set above;
- Theme Pack greyboxes;
- fail = Hurt / wasted Action / bad position.

## V2

- richer cover;
- more furniture verbs;
- more Theme Packs.

## V3

- denser generated arena tag grammar from seed + theme;
- still reject freeform physics parkour as arena gameplay truth.

# Anti-Patterns

- treating overworld or interiors as grid-authored gameplay space;
- building pretty arenas and bolting turns on later without cell tags;
- Environment Actions only in cutscenes;
- 0% fail fantasy jumps that delete Commitment;
- giving Confront unique traversal verbs denied to Veil/Withdraw;
- giant action list before the six Approaches feel good;
- requiring 1:1 geometry clone of the exploration scene for every arena.
