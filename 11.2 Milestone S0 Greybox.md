> **Deprecated (2026-08-09).** This document specified the **pre-pivot** grid-district greybox: a continuous, cell-snapped Lower Veil built on the now-retired [13 City Generation](13%20City%20Generation.md) scaffold. That spatial model is not viable ([16 Architecture Pivot](16%20Architecture%20Pivot.md)) and this milestone is not the current S0 target. Kept as historical record only — do not resume this task breakdown.

# What This Milestone Was

A walkable greybox proof of the Lower Veil fantasy locations (tavern, notice board, Harrow & Tincture, Loom Lane, coal stairs) built on a square-grid district footprint with A* pathing, cell-snapped landmarks, and district-wide `GridMap` walkability. It shipped and was frozen on 2026-08-06 as the base for the (now also archived) S1/S2 stubs.

# Why It Was Retired

Superseded in full by the [16 Architecture Pivot](16%20Architecture%20Pivot.md): the district-wide grid it was built on is no longer gameplay truth anywhere except Combat Arenas, and the Vertical Slice's real S0 target is a free third-person Overworld stub, not a grid-district greybox.

# What Replaces It

[11 Vertical Slice](11%20Vertical%20Slice.md) already defines the current **Milestone S0 — Greybox / post-pivot stub**: seeded overworld stub + free 3P walk, one interior scene (tavern), board/talk stubs, POI shell markers. The concrete build order for that milestone lives in [16 Architecture Pivot](16%20Architecture%20Pivot.md) §7 / [17 Game Systems Architecture](17%20Game%20Systems%20Architecture.md) Wave W/L/I, detailed further in `unity/Assets/Plans/OVERWORLD_V0_PLAN.md`.

The **content** ideas here (which named landmarks/POI shells exist, what the Notice Board pins, stub NPC names) may still inform authoring the new overworld stub, but the spatial/implementation instructions (square grid, A* click-move, `GridMap` district footprint, `GameDev → S0` menu) are archive only.

Code under `unity/` implementing this milestone (`Assets/Scenes/S0_LowerVeil.unity`, `Assets/Prefabs/S0_Greybox/`) remains in the repository as archive per [001 Documentation Standards](001%20Documentation%20Standards.md) but must not be extended.
