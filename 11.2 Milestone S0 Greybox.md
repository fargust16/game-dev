# Purpose

Milestone **S0** builds a walkable greybox of Lower Veil District.

It proves space, pacing, and stub interaction before real POI logic, combat, or pretty art.

Success question:

> Can a player walk the district, find the key landmarks, and talk to stub NPCs without getting lost or bored in 5–10 minutes?

# Explicitly Out of S0

Do **not** build these yet:

- full Decision Node outcomes;
- Active Window timers / unattended resolution;
- full Confront combat resolution;
- Pathway / Bargain power;
- Influence simulation;
- Death Gap;
- final art, animation, audio mix;
- full World Seed procedural generation;
- save systems beyond a simple debug reload if needed.

If a task needs any of the above, it belongs to S1+.

# Grid-First Requirement

S0 **does** require a square gameplay grid from the first blockout.

- all floors/landmarks snap to grid cells;
- debug draw of grid is on by default;
- Move preview can be stubbed as cell highlighting;
- at least 3 Environment Action tags exist in the district (vault, window, climb/stairs ledge);
- free-walk camera may exist for looking around, but gameplay space is authored on grid.

Full Turn-Based Mode initiative/Confront can wait for S3, but space must not be built off-grid.

# Engine Note

Engine lock: Unity in `unity/` — see [12 Engine Choice](12%20Engine%20Choice.md).

S0 requires:

- grid-legal navigable space;
- collision / cell occupancy;
- camera usable for exploration;
- interact prompts;
- stub dialogue text;
- debug labels for locations/POI shells;
- debug grid visibility.

# Player Capabilities in S0

The player can:

1. move through the district on grid-legal paths (continuous presentation allowed if grounded on cells);
2. look around with a readable camera;
3. open a simple interact prompt on marked spots / tagged cells;
4. read stub Notice Board text;
5. talk to stub Bartender and 1–2 street NPCs (linear stub lines are enough);
6. enter/exit key interiors or clearly framed front spaces;
7. see debug names for future POI shells (A/B/C) without full gameplay;
8. attempt at least one stub Environment Action (for example vault crate or window prompt that logs success/fail).

Optional nice-to-have, still S0:

- day/night lighting toggle for mood check;
- simple world-time debug display (not full Active Windows yet);
- manual Turn-Based Mode toggle with Move cell preview only (no combat).

# Greybox Locations

Build these as blocked volumes first. Beauty later.

| ID | Location | Must communicate | S0 interact |
|----|----------|------------------|---------------|
| L0 | **Ridge Approach** (spawn) | richer road above / poor drop into Lower Veil | spawn point, look-down beat |
| L1 | **Soot & Bell Tavern** exterior + interior stub | hub, warmth vs soot outside | enter; talk Bartender stub |
| L2 | **Notice Board** by tavern | public info spine | read 2–3 pinned stub notices |
| L3 | **Tincture Row** | medicine street, narrow shops | walk; see Harrow & Tincture front |
| L4 | **Harrow & Tincture** shop front | POI A shell | interact "future arrest scene"; no full node |
| L5 | **Loom Lane** | mill-girl street, factory pressure | walk; hear/see factory wall mass |
| L6 | **Coal Stairs** | POI C shell under factory wall | reach landing; debug trace marker |
| L7 | **Factory Wall / Whistle point** | era mood, shift-bell landmark | visible landmark; optional whistle debug trigger |
| L8 | **Alley Mouth** (Loom → coal stairs) | POI B coach/abduction shell | reach alley; debug collector marker |

Keep the route compact: spawn → tavern/board → Tincture Row → Loom Lane → coal stairs should be learnable in one loop.

# Recommended Blockout Loop

```text
Ridge Approach (spawn)
    ↓
Soot & Bell + Notice Board
    ↓
Tincture Row (POI A front)
    ↓
Loom Lane (POI B street)
    ↓
Alley Mouth → Coal Stairs (POI C)
    ↓
short return path to tavern
```

No maze. One memorable vertical/class contrast at spawn is enough.

# Stub Content Checklist

## Notice Board stubs

Pin exactly three readable notes:

1. Warden seizure notice for Harrow & Tincture before second-shift bell.
2. Missing-person paper for Loom Lane.
3. Harmless flavour (shift wages / coal price) for world texture.

No map Marking logic yet — text only.

## Bartender stub

Name placeholder: **Merrin** of the Soot & Bell.

Lines (branchless is fine):

- welcome to Lower Veil;
- mention brass-numbers and second-shift whistle;
- mention eleventh-bell collectors;
- invite player to check the board.

## Street NPCs

Two stubs max:

- mill neighbour on Tincture Row (cough / medicine worry);
- door-watcher near Loom Lane (afraid after dark).

## POI shells

Place debug volumes:

- `POI_A_SHELL` at Harrow front;
- `POI_B_SHELL` at Loom alley mouth;
- `POI_C_SHELL` at coal stair landing.

Interacting prints/logs: "S1 will start Decision Node X".

# Mood Pass (Still Greybox)

Even in greybox, sell era with cheap signals:

- different ground materials/colors for ridge vs lower streets;
- taller cleaner blocks visible upridge;
- factory mass and chimney stubs;
- gaslamp posts (untextured primitives ok);
- narrower streets in Lower Veil than ridge road;
- one horse-cab proxy on ridge, carts/crates below.

Do not spend S0 on final meshes.

# Acceptance Criteria

S0 is done when:

1. Player can complete the full landmark loop without falling out of world.
2. Tavern, board, Harrow front, Loom Lane, coal stairs are all findable without a guide.
3. Board and bartender communicate the two future leads in stub form.
4. POI A/B/C shells exist and are reachable.
5. Grid debug is visible and landmarks are cell-snapped.
6. At least one Environment Action stub can be attempted with a logged success/fail.
7. A new playtester can explain, after one run: “Poor factory district under richer streets; tavern is the hub.”
8. No dependency on full combat or real POI resolution.

# Task Breakdown for One Developer

## S0.1 — Space

- create square grid for the district footprint;
- block ridge spawn and lower streets on-grid;
- collision / blocked cells and fall boundaries;
- landmark silhouettes (tavern, factory wall, shop row) snapped to cells.

**Unity:** menu `GameDev → S0 → Create Lower Veil Greybox Scene` builds `Assets/Scenes/S0_LowerVeil.unity` from `Assets/Prefabs/S0_Greybox/` (grid + landmarks + player).

Controls (S0) — BG3-like split:

- **LMB** — click-to-move avatar;
- **Arrow keys** — walk avatar (free) / cell step (Turn-Based);
- **WASD** — pan camera (free, not glued to character);
- **Q / E** — rotate camera; **RMB drag** — orbit; **Wheel** — zoom; **F / Home** — focus avatar;
- **E** — interact (on-screen toast + Console);
- **T** — toggle Turn-Based cell steps (stub) vs free exploration.

Prefab scale reference: `Assets/Scenes/S0_Greybox_Test.unity` (optional).

## S0.2 — Route

- connect loop tavern ↔ Tincture ↔ Loom ↔ stairs;
- add simple signage/debug arrows only if playtests get lost;
- tune travel time to feel short and readable.

## S0.3 — Interact stubs

- board read UI/text dump;
- bartender talk stub;
- two street NPC stubs;
- three POI shell prompts;
- stub Environment Actions on tagged cells (vault / window / climb ledge).

**Note:** S0.1 builder already includes Console stubs for board, bartender, POI A/B/C shells, and vault/window/climb. S0.3 polish = UI / NPC props, not new systems.
## S0.4 — Mood check

- lighting day/night toggle or two lighting setups;
- class contrast readable in screenshot;
- factory whistle debug sound optional.

## S0.5 — Playtest gate

- one external or self playtest with acceptance list;
- note navigation confusion;
- freeze S0 and move to S1 only after acceptance.

# Exit Into S1

When S0 passes, S1 begins:

- tips create Hinted/Marked states;
- Active Windows tick;
- unattended resolution stubs write Aftermath flags.

S1 must not restart greybox from zero; it dresses logic onto these shells.

# Risks

| Risk | Mitigation |
|------|------------|
| District too big | cut side streets; keep one loop |
| Pretty-art trap | primitives only; mood via proportion/light |
| Hidden systems creep | refuse timers/combat until S1/S3 |
| Player misses coal stairs | tavern line + visible factory wall magnet |
